Independently inspectable mathematical statements

This independent specification is rebuilt from Mathlib primitives. The six propositions in Statements.lean use only Mathlib and the definitions in Definitions.lean. Neither file imports the proof library. The statements and all definitions needed to interpret them can therefore be inspected without reading that library.

The results concern Henri Martikainen's The Zygmund conjecture and Rey's exponential integrability conjecture. The central statements are the weakly incomparable maximal estimate, the sparse weakly incomparable overlap estimate, and the continuous Zygmund endpoint. The overlap estimate proves Rey's conjecture. The rounded endpoint supports the continuous result; the other two statements concern overlap for sparse Φ-Zygmund families and sharpness for the classical dyadic Zygmund family.

The propositions and their proofs are in the namespace ReyZygmund.MathlibOnly. Solutions.lean derives the six statements from the proof library's theorems. The consistency guide explains the connections between the specification's definitions and those used in the proofs.

The maximal statement uses the paper's 1 < p ≤ 2 range. The underlying theorem proves the same weakly incomparable estimate for every real p > 1.

The maximal function and overlap take values in [0, ∞]. The maximal and overlap bounds use these quantities directly.

The sharpness result concerns the classical dyadic Zygmund family. Here n = m - 1, where m is the number of cube factors. For n ≥ 2, 0 < eta < 1 and any choice of dyadic grids in the n + 1 cube factors, it gives a sequence of finite incomparable eta-sparse families G_N, N ≥ 2, whose unions have measure one. For every c > 0 and beta > 1/n, the integrals of exp(c h^beta) over these unions tend to infinity, where h is the overlap function of the corresponding family. The same sequence works for all such c and beta.

The mathematical objects used in the six statements are defined in Definitions.lean:

Boxes, finite coordinate products, Lebesgue measure, integrals, extended nonnegative numbers, powers and norms use Mathlib's definitions directly. The Lean source comments explain the notation used in these definitions and statements.

A box Q has corner tuples Q.lower and Q.upper; the expression (Q : Set (Fin d → ℝ)) denotes the product of the intervals (Q.lower j, Q.upper j]. In the sharpness statement, Tendsto (fun N => a N) atTop atTop means a N → +∞ as N → ∞.
